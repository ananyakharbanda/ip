## Viewing statistics

Use `stats` to view a summary of the tasks currently managed by Duchess.
The completion count includes all completed tasks, while the seven-day count
includes completed tasks whose latest known completion time is within the
previous seven days.

Example: `stats`

```text
Task statistics:
Total tasks: 2
Completed tasks: 1
Incomplete tasks: 1
Completed in the past 7 days: 1
Completion rate: 50%
```

The command takes no arguments. Existing task files without completion
timestamps remain readable; those completed tasks are included in the overall
completion count but not in the seven-day count.
